# Changelog

All notable changes to the SPOP profile Draft will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project aims to follow [Semantic Versioning](https://semver.org/) once it leaves Draft status.

## [0.1.0-draft] – 2026-07-28

### Added

- Initial Draft specification (`spec/spop-profile.md`)
- Lightweight vocabulary (`vocabulary/spop.ttl`)
- Draft SHACL shapes for minimum provenance (`spec/spop-shape.ttl`)
- Turtle examples for basic, `org_value`, `process`, and `informational` usage
- README, CONTRIBUTING, Apache-2.0 LICENSE

### Notes

- Status remains **Draft**; no stability guarantees.
